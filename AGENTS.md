## Agent behavior

- On reply be concise; drill down on request.
- Before marking work done, re-read the diff as a reviewer.

## Code

- When adding new dependencies always check if we are adding the latest stable version.
- Don't commit changes unless the user asks to.

## Git conventions

- When creating a new branch don't add a prefix.
- Commit messages should be consice and short without a `co-author` section.
